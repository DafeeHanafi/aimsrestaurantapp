# aimsrestaurantapp

Digital QR Menu & Nasi Campur POS for Aims Solutions Sdn. Bhd.

Standalone project. Not connected to `theoccasions-booth-booking` or `toc-finance`.

## Local

```powershell
cd "C:\Users\USER\aimsrestaurant app"
npm install
npm start
```
